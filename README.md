# Трекер стендов

Общий сайт для AAV, ALP, OVD и TVE. Показывает, кто сейчас работает на каждом стенде, сколько времени прошло, приоритет задачи, планируемое время освобождения и запрос коллеги «освободить до …» с причиной. После освобождения сеанс остаётся в истории.

Рабочая версия: https://crysingzz.github.io/stand-tracker/. Она подключена к проекту Supabase `stand-tracker` в организации `stands-amazing-people`. Участникам нужен командный код, который передаётся отдельно от ссылки.

## Как устроено

- GitHub Pages отдаёт статический сайт из папки `docs`.
- Supabase хранит общую занятость, историю и шесть профилей команды. Серверные операции реализованы функциями PostgreSQL; Telegram-вход и уведомления обслуживает одна Edge Function.
- Общий код команды проверяется в базе. Сам код **не хранится в репозитории**. URL проекта и *publishable key* в `docs/config.js` предназначены для браузера; `secret` и `service_role` ключи туда помещать нельзя.
- Стенды и история обновляются каждые 15 секунд. Таймер текущей работы идёт локально каждую секунду.
- Сейчас вход по общему коду остаётся доступен, пока команда не подключила Telegram-бота. В этом режиме имя по-прежнему вводится вручную. После подключения бота сайт предложит Telegram-вход, а новые действия в этом режиме будут записываться на подтверждённый профиль.

## Подключение Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. Передайте администратору только `@username` бота; токен не отправляйте в чат и не добавляйте в репозиторий.
2. В @BotFather выполните `/setdomain` и задайте `crysingzz.github.io` (без `https://` и пути `/stand-tracker/`). Это нужно для Telegram Login Widget на GitHub Pages.
3. В [Supabase → Edge Function Secrets](https://supabase.com/dashboard/project/kegynudaiydthomudwzd/functions/secrets) добавьте секрет с именем `TELEGRAM_BOT_TOKEN` и значением токена от BotFather. Функция `stand-tracker-api` уже развёрнута; после добавления секрета она сама получит публичный `@username` бота через Telegram API. Токен остаётся только на сервере.
4. Каждый участник входит на [сайт](https://crysingzz.github.io/stand-tracker/) через Telegram своим аккаунтом из списка ниже и открывает бота, нажимая **Start**. При первом входе сайт связывает профиль со стабильным Telegram ID. Изменение @username после этого не разрывает привязку. Войти под чужим именем простым вводом @username нельзя: сервер проверяет подпись Telegram.
5. Проверьте на двух аккаунтах: один занимает стенд, другой отправляет запрос. Первый должен получить сообщение; после освобождения второй получает сообщение. Если Telegram не принял сообщение, сайт сохранит действие и покажет предупреждение.

Профили: Глеб Сорвачев — `@crysingzz`; Илья Скворцов — `@fgtuioth`; Кирилл Долматов — `@kirill_dolmatov`; Артём Попов — `@appetrovich1`; Иван Черепенников — `@ivanya13`; Иван Штыров — `@Shtyroffid`. Пока участник не вошёл через Telegram, его профиль создан, но Telegram ID ещё не привязан и личное уведомление ему доставить нельзя. Также нельзя уведомить владельца старого сеанса, созданного до привязки профилей.

После проверки входа всех участников нужно убрать кнопку «Войти по коду команды» из сайта и выполнить [`supabase/manual/retire_shared_code_after_telegram.sql`](supabase/manual/retire_shared_code_after_telegram.sql). До этого момента общий код остаётся резервным способом входа и позволяет ручной ввод имени; он не обеспечивает подлинность личных аккаунтов.

## Развёртывание своей копии с Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/dashboard).
2. Откройте **SQL Editor** и выполните целиком [`supabase/schema.sql`](supabase/schema.sql), затем по порядку [`20261005_priority_and_members.sql`](supabase/migrations/20261005_priority_and_members.sql) и [`20261005_telegram_member_api.sql`](supabase/migrations/20261005_telegram_member_api.sql). Они не удаляют существующие сеансы.
3. В **Project Settings → API Keys** возьмите Project URL и *publishable key* вида `sb_publishable_…`.
4. Заполните только эти два значения в [`docs/config.js`](docs/config.js). Секретный код команды передаётся участникам отдельно.
5. Откройте сайт, введите код команды и проверьте занятие и освобождение AAV. Затем откройте сайт на другом устройстве и убедитесь, что изменение видно там.

Таблицы находятся в закрытой схеме `private`. Прямое чтение и изменение таблиц из браузера запрещены. Старые функции проверяют общий код. Новые функции для личных профилей доступны только серверной функции, которая сначала проверяет Telegram-подпись. Токен бота и серверный ключ Supabase не отдаются браузеру.

## GitHub Pages

Создайте публичный репозиторий и включите Pages для папки `/docs` ветки `main` в **Settings → Pages**. Сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`. Код команды не добавляйте в файлы сайта или репозиторий. Если `docs/config.js` изменился после публикации, загрузите новый коммит и дождитесь обновления Pages.

Для локального просмотра: `python3 -m http.server 8765 --directory docs` и откройте `http://localhost:8765`. Пока `docs/config.js` пустой, сайт показывает экран ожидания подключения и не принимает действия.

На бесплатном плане Supabase проект может приостанавливаться после недели низкой активности; его можно возобновить в панели управления. Поэтому если сайт долго не использовали и он показывает «Нет связи», проверьте состояние проекта Supabase.
