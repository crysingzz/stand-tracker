# Трекер стендов

Общий сайт для AAV, ALP, OVD и TVE. Показывает, кто сейчас работает на каждом стенде, сколько времени прошло, приоритет задачи, планируемое время освобождения и запрос коллеги «освободить до …» с причиной. После освобождения сеанс остаётся в истории.

Рабочая версия: https://crysingzz.github.io/stand-tracker/. Она подключена к проекту Supabase `stand-tracker` в организации `stands-amazing-people`. Вход доступен только участникам команды через Telegram.

## Как устроено

- GitHub Pages отдаёт статический сайт из папки `docs`.
- Supabase хранит общую занятость, историю и шесть профилей команды. Серверные операции реализованы функциями PostgreSQL; Telegram-вход и уведомления обслуживает одна Edge Function.
- Браузер получает одноразовую ссылку на бота, а код приходит в личный чат Telegram. Сервер связывает ответ бота с разрешённым профилем и выдаёт отдельный отзывной сеанс сайта. В `docs/config.js` находится только публичный URL проекта; токен бота и серверный ключ туда помещать нельзя.
- Стенды и история обновляются каждые 15 секунд. Таймер текущей работы идёт локально каждую секунду.
- Старый вход по общему коду закрыт и в интерфейсе, и на уровне прав базы данных. Уже созданные сеансы и история сохраняются.

## Подключение Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. Передайте администратору только `@username` бота; токен не отправляйте в чат и не добавляйте в репозиторий.
2. В [Supabase → Edge Function Secrets](https://supabase.com/dashboard/project/kegynudaiydthomudwzd/functions/secrets) добавьте секрет `TELEGRAM_BOT_TOKEN` со значением токена от BotFather. Функция `stand-tracker-api` настраивает защищённый webhook и получает публичный `@username` бота. Токен остаётся только на сервере. `/setdomain` для этого способа входа не нужен.
3. На [сайте](https://crysingzz.github.io/stand-tracker/) нажмите «Получить код в Telegram», откройте приложение Telegram кнопкой, нажмите **Start** в личном чате бота и введите восьмизначный код. Если приложение не открылось, скопируйте показанную команду `/start …` и отправьте её боту вручную. Telegram-сессия в браузере не требуется. При первом входе сайт связывает разрешённый профиль со стабильным Telegram ID; позже смена @username не разрывает привязку. Код действует 5 минут, допускает не более 5 ошибок и используется один раз.
4. После входа нажмите «Проверить Telegram»: бот отправит тестовое сообщение. Затем проверьте на двух аккаунтах: один занимает стенд, другой отправляет запрос. Первый должен получить сообщение; после освобождения второй получает сообщение. Если Telegram не принял сообщение, сайт сохранит действие и покажет предупреждение.

Профили: Глеб Сорвачев — `@crysingzz`; Илья Скворцов — `@fgtuioth`; Кирилл Долматов — `@kirill_dolmatov`; Артём Попов — `@appetrovich1`; Иван Черепенников — `@ivanya13`; Иван Штыров — `@Shtyroffid`. Пока участник не вошёл через Telegram, его профиль создан, но Telegram ID ещё не привязан и личное уведомление ему доставить нельзя. Также нельзя уведомить владельца старого сеанса, созданного до привязки профилей.

Сеанс сайта хранится только в `sessionStorage` вкладки, переживает обновление страницы, действует не более 12 часов и отзывается кнопкой «Выйти». После закрытия вкладки потребуется новый код. Код и токен бота браузер не сохраняет. Другие старые Telegram-подтверждения для входа больше не принимаются.

## Развёртывание своей копии с Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/dashboard).
2. Откройте **SQL Editor** и выполните целиком [`supabase/schema.sql`](supabase/schema.sql), затем миграции в таком порядке: `20261005_priority_and_members.sql`, `20261005_telegram_member_api.sql`, `20261005_member_indexes.sql`, `20261005_telegram_only_cutover.sql`, `20261005_legacy_request_ownership_fix.sql`, `20261005_idempotent_telegram_binding.sql`, `20261005132624_bot_code_auth.sql`, `20261005135007_index_bot_login_challenge_member.sql`. Они не удаляют существующие сеансы стендов.
3. Настройте токен бота в секретах Edge Function и разрешённый адрес сайта в `allowedOrigins` функции.
4. Заполните публичный Project URL в [`docs/config.js`](docs/config.js).
5. Откройте сайт, войдите через Telegram и проверьте занятие и освобождение стенда. Затем откройте сайт на другом устройстве и убедитесь, что изменение видно там.

Таблицы находятся в закрытой схеме `private`. Прямое чтение и изменение таблиц из браузера запрещены. Функции для личных профилей доступны только серверной функции, которая проверяет одноразовый код и сеанс. Webhook принимает только запросы с секретным заголовком Telegram. Старые функции с общим кодом не разрешены браузерным ролям.

## GitHub Pages

Создайте публичный репозиторий и включите Pages для папки `/docs` ветки `main` в **Settings → Pages**. Сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`. Не добавляйте токен бота или серверные ключи в репозиторий. Если `docs/config.js` изменился после публикации, загрузите новый коммит и дождитесь обновления Pages.

Для локального просмотра: `python3 -m http.server 8765 --directory docs` и откройте `http://localhost:8765`. Пока `docs/config.js` пустой, сайт показывает экран ожидания подключения и не принимает действия.

На бесплатном плане Supabase проект может приостанавливаться после недели низкой активности; его можно возобновить в панели управления. Поэтому если сайт долго не использовали и он показывает «Нет связи», проверьте состояние проекта Supabase.
